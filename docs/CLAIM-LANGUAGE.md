# Claim language

## Allowed (after Definition of Done on the desk plan)
Built and operate a personal Kubernetes lab (kind): Helm-packaged workloads, rolling updates, Services/Ingress, NetworkPolicy, kubectl troubleshooting.

## Forbidden
- Production Kubernetes at DISA / DoD
- CKA certified (until exam scored)
- Platform engineer owning prod clusters
- Claiming Infoblox/NSX as kind work (those are separate DISA prod claims)
